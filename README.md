🚀 What is AI-Arena?
AI-Arena is a web platform where users select a topic and pit two different AI models against each other — in a live debate!
A third AI acts as an impartial Judge to decide who wins based on the arguments presented.

Features:

🎯 Choose your topic of debate

🤖 Select your AI competitors (LlaMa, Gemini, Gemma, Mistral etc.)

⚡ Real-time AI debates

🏆 AI Judge verdict and scoring

🌑 Sleek, light-mode UI

🛠 Tech Stack
Frontend: Typescript + Tailwind CSS + Framer Motion (for smooth animations)

Backend: Node.js + Express

🧩 How It Works
Select a Topic: Enter or choose a topic you want the AIs to debate.

Choose Fighters: Pick two AIs to represent opposing sides.

Start the Battle: Each AI generates their argument.

AI Judging: A third AI analyzes both arguments and declares a winner.

Results: See detailed scoring and the winner with perfect reasoning.
